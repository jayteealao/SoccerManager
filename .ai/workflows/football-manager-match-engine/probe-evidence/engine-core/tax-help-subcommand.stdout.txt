Simulate one match and write every tick to a file

Usage: engine-cli.exe simulate [OPTIONS] --seed <SEED> --ticks-out <FILE>

Options:
      --seed <SEED>        Seed for the engine's random-number generator
      --ticks-out <FILE>   Path of the tick file to write
      --minutes <MINUTES>  Minutes of play to simulate [default: 90]
      --json               Also write a JSON Lines dump of every tick next to the tick file (`<FILE>.jsonl`)
  -h, --help               Print help
