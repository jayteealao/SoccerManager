Headless command line for the football match engine: simulate and bench

Usage: engine-cli.exe <COMMAND>

Commands:
  simulate  Simulate one match and write every tick to a file
  bench     Time whole matches on one thread and print a run report
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
